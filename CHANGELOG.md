# История изменений

## 0.6.0 — переработка интерфейса и структуры

- Заменены маркетинговые и декоративные экраны на компактный интерфейс настройки сервера.
- Упорядочены цвета, шрифты, подписи, состояния кнопок и сообщения пользователю.
- Разделены `main.go`, `app.go`, `api.go` и `installer.go`. Внешние API сохранены.
- Исправлена навигация клавиатурой внутри подтверждающих диалогов.
- Улучшена обработка потери связи с локальным API при установке.
- ANSI-последовательности терминала удаляются из журналов перед показом.
- README и технические ограничения переписаны в виде краткой эксплуатационной документации.

## 0.5.0 — совместимость Xray

- Поддержаны варианты вывода X25519 `PrivateKey` / `Password (PublicKey)`.
- Повторное скачивание уже установленного Xray пропускается.

## 0.4.0 — управление портами

- Проверка занятости TCP/UDP, выбор альтернативного порта.
- Остановка поддерживаемых служб после подтверждения.

## 0.3.0 — фоновая установка

- Тихий запуск системных команд Windows.
- Резервный переносной SSH-клиент и установка HAPP через WinGet.

# История изменений

## Подготовка к публикации

- Сборки Windows и Linux и черновики релизов в GitHub Actions.
- Локальный интерфейс принимает запросы только к loopback-адресу.
- Обновлены инструкции по запуску и проверкам.

## 0.6.0

- Обновлён интерфейс настройки VPS.
- Запуск, локальный API и установка разнесены по отдельным файлам.
- Исправлено подтверждение остановки службы при занятом порте.
- В журнале отфильтровываются управляющие последовательности терминала.

## 0.5.0

- Добавлена поддержка новых форматов вывода X25519 в Xray.
- Уже установленный Xray используется повторно.

## 0.4.0

- Добавлены проверка TCP/UDP-портов, подсказки свободных портов и остановка распознанной службы по подтверждению.

## 0.3.0

- Служебные процессы Windows запускаются без отдельного окна консоли.
- Добавлены переносной SSH-клиент и установка HAPP через WinGet.

# Portline — дизайн-система

## Задача интерфейса

Portline — утилита установки на VPS, не аналитический дашборд и не рекламный сайт. Интерфейс должен помогать человеку с минимальными техническими знаниями выполнить четыре понятных шага и понимать последствия операций на сервере.

## Характер

Визуальный ориентир — небольшая профессиональная системная утилита: аккуратные формы, плотный ритм, спокойная типографика и заметные, но не навязчивые состояния. Отличительная деталь — схема ПК / VPS, показывающая предмет работы, а не вымышленную «живую телеметрию».

Не использовать: кислотные градиенты, декоративные графики, маркетинговые лозунги, липовые метрики, декоративные загрузчики и утверждения о безопасности без проверяемых оснований.

## Токены

Канонический источник значений — `ui/style.css` (`:root`). Этот документ объясняет назначение токенов, но не генерирует отдельную тему.

| Роль | Значение |
|---|---|
| Рабочий фон | `#edf1f3` |
| Поверхность | `#ffffff` |
| Навигация | `#22323b` |
| Основной текст | `#243640` |
| Вторичный текст | `#60717a` |
| Граница | `#dce4e8` |
| Основное действие | `#267687` |
| Выделение | `#e9f4f5` |
| Ошибка | `#9e3c35` |
| Предупреждение | `#8a6025` |

**Типографика:** Segoe UI Variable / Segoe UI для текста; Bahnschrift — заголовки и название продукта; Cascadia Code / Consolas — адреса, номера портов, журналы и шаги. Специальная загрузка шрифтов не требуется.

**Компоненты:** кнопки высотой 40 px, поля 42 px, радиус 7–9 px; информационные панели отделяются рамкой, не тяжёлой тенью. Широкий экран — боковые этапы, основной шаг и параметры VPS; на узком экране этапы переходят в горизонтальный ряд, вторичная колонка скрывается.

## Поведение

Визуальные состояния идут за фактическим статусом операции: `idle`, `running`, `success`, `error`. Шаг установки не подменяется обещанием «связь защищена». Анимация допускается только для смены шага и настоящего состояния загрузки (не более 230 ms для перехода панели). Учитывать `prefers-reduced-motion`.

Подтверждения остановки служб и запуска удалённой установки блокируют случайный клик, удерживают клавиатурный фокус внутри диалога и возвращают его после закрытия. Ошибки и подсказки не должны сдвигать кнопки во время загрузки.

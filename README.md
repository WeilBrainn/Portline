# Portline

Portline настраивает Xray (VLESS + REALITY) или Hysteria 2 на вашем Linux VPS по SSH. После установки приложение выдаёт ссылку для импорта в HAPP. Подключение и режим TUN настраиваются в самом HAPP.

## Запуск

- **Windows x64** — запустите `Portline.exe`. Интерфейс откроется в окне Edge или в браузере по умолчанию.
- **Linux x64** — распакуйте архив и запустите `./portline-linux-amd64`. Нужны OpenSSH и браузер.

Готовые сборки и файл с контрольными суммами находятся в разделе [Releases](https://github.com/WeilBrainn/Portline/releases).

## Настройка VPS

1. Укажите адрес, порт SSH и пользователя. Войти можно по паролю или закрытому ключу. На сервере нужны `root` или настроенный заранее `sudo -n`.
2. Выберите VLESS + REALITY (TCP) или Hysteria 2 (UDP) и проверьте, свободен ли выбранный порт. Если он занят, Portline предложит другой. Распознанную службу можно остановить после подтверждения.
3. Запустите установку и дождитесь ссылки. Portline создаёт конфигурацию, запускает службу systemd и при необходимости открывает порт в активном локальном firewall. Правила облачного firewall меняются в панели провайдера.
4. Импортируйте ссылку в HAPP. Для маршрутизации через TUN включите его в HAPP и проверьте внешний IP, DNS и IPv6.

Установщики рассчитаны на Debian, Ubuntu, Fedora и семейство RHEL с systemd на x86-64 или ARM64. Состояние существующей службы и её конфигурацию стоит проверить перед переустановкой. Скрипты делают копию прежнего файла конфигурации, если он есть. Автоматического отката нет.

### SSH и профили

На Windows Portline сначала ищет OpenSSH. Если его нет, для пароля или ключа `.ppk` приложение может скачать Plink и сверить закреплённую контрольную сумму. Для ключа OpenSSH используется системный клиент. При установке компонента Windows или HAPP может появиться системный запрос.

Ссылка подключения содержит секрет. Для Hysteria 2 клиент должен проверять `pinSHA256` самоподписанного сертификата. Сертификат действует 365 дней, его нужно обновить вручную.

## Сборка из исходников

Нужен Go 1.21 или новее. HTML, CSS, JavaScript и скрипты установки встраиваются в бинарник при сборке.

**Windows**

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

**Linux**

```bash
./build.sh
```

Скрипты запускают `go test ./...` перед сборкой. GitHub Actions проверяет проект на Windows и Linux. Тег вида `v0.6.0`, совпадающий с версией в `main.go`, создаёт черновик релиза с обеими сборками и контрольными суммами. Установка на VPS и импорт в HAPP требуют отдельной ручной проверки.

# Portline

Portline — локальное приложение для подготовки собственного Linux VPS под VLESS + REALITY или Hysteria 2. Пользователь вводит SSH-доступ, выбирает протокол и получает ссылку конфигурации, которую можно импортировать в HAPP.

Приложение **не является VPN-клиентом**: оно управляет сервером по SSH. Трафик Windows и работа TUN остаются на стороне HAPP.

## Возможности

- Подключение к VPS по SSH с паролем или приватным ключом.
- Установка Xray или Hysteria 2 и настройка systemd.
- Проверка TCP/UDP-порта, предложение свободных портов и остановка *распознанной* службы после подтверждения.
- Резервное копирование ранее существующей конфигурации выбранной службы.
- Получение ссылки `vless://` или `hysteria2://` без записи секрета в журнал.
- Копирование профиля, сохранение его в файл и открытие в HAPP.
- Установка HAPP через WinGet (если он доступен).
- Фоновое выполнение команд без консольных окон на Windows. Запросы UAC остаются видимыми.

## Сборка из исходников

Нужен [Go](https://go.dev/dl/) 1.21+ (лучше актуальная стабильная версия). Node.js и npm не требуются. Go-зависимостей вне стандартной библиотеки нет.

**Windows:**

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

**Linux / Arch:**

```bash
./build.sh
```

**Windows EXE из Linux:**

```bash
CGO_ENABLED=0 GOOS=windows GOARCH=amd64 \
  go build -trimpath -ldflags='-H windowsgui -s -w' -o Portline.exe .
```

Самостоятельная проверка перед выпуском:

```bash
go test ./...
go test -race ./...
go vet ./...
bash -n scripts/*.sh
node --check ui/app.js
```

## Как работает установка

1. Portline запускает локальный HTTP-сервер на `127.0.0.1` с временным токеном доступа. Интерфейс открывается в режиме окна Microsoft Edge или в браузере по умолчанию.
2. После подтверждения установки выполняется SSH-подключение и удалённый Bash-скрипт. Пароль SSH не сохраняется в конфигурации Portline.
3. Скрипт устанавливает пакеты, подготавливает конфигурацию протокола, проверяет её и запускает службу systemd.
4. Готовая ссылка отображается в приложении. Скопируйте её в HAPP, включите TUN и проверьте маршрутизацию, DNS и IPv6.

На Windows используется системный OpenSSH. Если его нет, приложение пробует загрузить проверенную по SHA-256 переносную версию Plink. При необходимости предлагается установка штатного OpenSSH с системным запросом разрешений. Для нестандартных OpenSSH-ключей переносной Plink не подходит: используйте системный клиент.

Внешние консоли для вспомогательных процессов скрываются. **Это не означает обход UAC**, разрешений безопасности или установщиков сторонних программ.

## Структура

| Путь | Назначение |
|---|---|
| `main.go` | запуск приложения, локальный сервер и открытие интерфейса |
| `app.go` | входные данные, состояние и валидация |
| `api.go` | HTTP API и доступ из локального интерфейса |
| `installer.go` | сценарий установки и обработка результата |
| `transport.go` | OpenSSH, Plink, скачивание компонентов и SSH-журнал |
| `ports.go` | управление конфликтами TCP/UDP-портов |
| `happ.go` | установка HAPP через WinGet |
| `ui/` | HTML, CSS и JavaScript (без сборщика) |
| `scripts/` | удалённые Bash-скрипты |
| `*_test.go` | тесты ошибок, парсинга и локального API |

## Требования к серверу

Linux с `systemd`, `bash`, доступом `root` или пользователем с заранее разрешённым `sudo -n`. Поддерживаются Ubuntu, Debian, AlmaLinux, Rocky Linux, RHEL, CentOS и Fedora. Архитектуры `x86_64` и `aarch64`.

Перед использованием на рабочем VPS сделайте снимок или резервную копию. Установщик заменяет конфигурацию выбранного сервиса, обновляет зависимые пакеты и открывает порт в локальном firewall, если тот обнаружен. Полного автоматического отката пока нет.

Управление портом не изменяет настройки облачного firewall у хостера. Если 443 занят, предпочтительнее сменить порт. Остановка службы может прервать действующий сайт или VPN.

## Безопасность и ограничения

- Ссылка подключения содержит секреты. Храните её как пароль.
- OpenSSH применяет принцип «доверять при первом подключении» (TOFU). Для критичных серверов проверьте отпечаток SSH-ключа отдельно.
- Переносной Plink может кратковременно хранить SSH-пароль во временном файле профиля пользователя; файл удаляется по завершении процесса.
- Сценарий Hysteria 2 использует самоподписанный сертификат с закреплением SHA-256. В текущем установщике сертификат действует 365 дней и автоматически не продлевается.
- Установка Xray и Hysteria скачивает компоненты с внешних источников. Перед использованием в критичной инфраструктуре следует закрепить версии и проверить цепочку поставки.
- Трафик ПК не начинает идти через VPS автоматически. После импорта профиля в HAPP необходимо вручную проверить TUN, DNS/IPv6 и доступность нужных ресурсов.
- Portline не гарантирует отсутствие сетевых блокировок или определение географического положения сторонними сервисами.

## Что проверено

Для v0.6 выполнены локальные тесты Go и проверка сборки Windows/Linux. Удалённая установка на реальном VPS и автоматические системные сценарии Windows (UAC, WinGet, HAPP) не проходили интеграционные испытания в этой среде. Тестировать первую установку следует на чистом VPS.

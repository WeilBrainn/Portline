# Portline v0.3 — как устроена тихая установка

**Windows:** `process_windows.go` выставляет `HideWindow` и `CREATE_NO_WINDOW` для всех служебных дочерних процессов, вызываемых через `backgroundCommand` (PowerShell, ssh, Plink и WinGet). Браузерный GUI запускается обычным способом.

**SSH без OpenSSH:** если системный `ssh.exe` есть, используется он. Если нет — скрытый PowerShell запускает `Invoke-WebRequest` для фиксированной ссылки на официальный PuTTY 0.85, затем Go сверяет закреплённый SHA-256. Если PowerShell недоступен, Go скачивает тот же файл по HTTPS, проверяет тот же SHA-256 и только затем запускает. Если обе загрузки не удались, скрытый PowerShell пробует установить Windows Capability OpenSSH; UAC может потребовать разрешение.

**VPN на VPS:** фоновый SSH-процесс передаёт установочный скрипт через stdin. Вывод поступает только в встроенный журнал установки. Пароли и ссылки не записываются в этот журнал.

**HAPP:** асинхронный запуск `winget install --silent` через `backgroundCommand`; UI опрашивает отдельный статус. Если WinGet отсутствует, автоматически не открываются страницы и не запускаются неизвестные EXE — пользователю показывается официальная ссылка.

**Ограничения:** не скрываются системные запросы UAC, запросы драйвера, окна, запущенные сторонним установщиком помимо WinGet. Настройка HAPP/TUN по-прежнему производится пользователем в HAPP.

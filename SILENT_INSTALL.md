# Фоновые процессы Windows

`backgroundCommand` запускает PowerShell, OpenSSH, Plink и WinGet без отдельного окна консоли. Интерфейс открывается в Edge или в браузере по умолчанию. Windows и сторонние установщики по-прежнему могут показать запрос UAC или собственный диалог.

Если OpenSSH отсутствует, Portline пробует скачать Plink для подключения по паролю или ключу `.ppk`. Загрузка идёт через PowerShell с резервным HTTP-клиентом Go. Перед запуском сверяется SHA-256. Если Plink недоступен или нужен ключ OpenSSH, Portline пытается установить системный компонент OpenSSH Client.

При входе по паролю через Plink пароль временно передаётся через файл в каталоге Portline. Файл удаляется по завершении процесса. Во встроенном журнале ссылки подключения отфильтровываются.

HAPP устанавливается по отдельной кнопке через `winget install --silent`. Если WinGet недоступен, интерфейс показывает ссылку на официальные релизы HAPP. Настройки TUN задаются в HAPP.

# Portline — контракт поведения

Основная последовательность: **SSH-доступ → выбор протокола → установка → импорт профиля**. Внутри шага выбора можно проверить доступность порта, предложить замену и остановить подтверждённую службу из разрешённого списка.

## Обязательные состояния

- **SSH:** проверки полей до запроса, показ ошибки рядом с формой; пароль скрыт по умолчанию.
- **Протокол:** выбран ровно один вариант. Смена протокола или порта сбрасывает устаревшую проверку порта. `aria-pressed` отражает выбранную кнопку.
- **Порт:** `idle → running → free/busy/error`. Проверяется именно TCP для REALITY и UDP для Hysteria 2. Остановка недоступна, пока не получен отчёт о распознанной службе. Перед остановкой необходимо подтверждение.
- **Установка:** `idle → running → success/error`. Повторная установка — только после повторного подтверждения. На время выполнения блокируется завершение процесса через кнопку выхода.
- **Импорт:** ссылка скрыта по умолчанию; есть копирование, сохранение в файл, открытие в HAPP и отдельная установка HAPP по нажатию.

Ошибки должны содержать возможность восстановления. Задача по SSH может завершиться частично; приложение не утверждает, что откат уже выполнен. Если локальное соединение с интерфейсом потеряно, повторное нажатие «Установить» не следует рекомендовать до проверки VPS.

## Клавиатура и доступность

Поля связаны с `<label>`, ошибки форм используют `role=alert`, фоновые статусы — `role=status`. Доступность кнопок видима через focus-ring. Диалоги принимают Tab/Shift+Tab, Escape и возвращают фокус на элемент, который их открыл.

Интерфейс не перехватывает согласия UAC или запросы драйверов. Сторонние окна ОС и HAPP могут потребовать вмешательства пользователя.

## Приватность

Ключ подключения выдаётся только в локальном API с bearer-токеном и не помещается в журнал. Пароль SSH не записывается в пользовательскую конфигурацию; исключение: временный файл Plink для резервного пути. Экспорт ссылки в `.txt` инициируется самим пользователем.

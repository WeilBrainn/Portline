# Portline для Android

Для сборки установите JDK 17 и Android SDK Platform 35. Из папки `android` выполните `.\gradlew.bat :app:assembleDebug` в Windows или `./gradlew :app:assembleDebug` в Linux. Готовый APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

На Windows владелец выбирает «Экспортировать VPN-профиль». Получатель выбирает «Импортировать файл профиля» на Android или «Импортировать VPN-профиль» на Windows. Файл содержит адрес, порт, отпечаток публичного ключа и общий токен доступа к VPN. Передавайте его лично.

Gateway 1.4.0 выделяет отдельный IPv4-адрес каждому новому клиенту. Для одновременного подключения используйте Windows-клиент 1.4.0 или Android 10+. С обновлением Gateway перезапускается служба на VPS. Старый Gateway обслуживает одного клиента за раз.

В Android подтвердите системный запрос на запуск VPN. Клиент передаёт IPv4. Для блокировки трафика при отключении включите системные настройки Always-on VPN и «Блокировать подключения без VPN».
